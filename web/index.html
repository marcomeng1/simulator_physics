Physics engines for robotics, revisited

A reproduction of Manda Robotics' engine comparison with MuJoCo 4.0, MuJoCo-Warp 4.0, Newton 1.7 and Genesis 1.4.5

What was run

Every route loads the same MJCF scene. MuJoCo, MuJoCo-Warp and Genesis read it through the MuJoCo compiler, and Newton reads it through its own importer. Each route gets the same initial state, the same efforts or frozen controller tape, and the same timestep. The model is the Franka Panda from MuJoCo Menagerie at the article's pinned revision. Each route has its own locked uv environment. The Panda reference and feedforward tapes are generated once on MuJoCo 3.11, as in the article.

Phases: (1) single-object controls, (2) a three-object collision chain, (3) the Panda: open-loop effort, joint tracking, grasping, stacking and channel pushing, (4) what MuJoCo 4.0 changes and how sensitive the results are to solver options, (5) runtime from one world up to 131,072 worlds.

The article does not publish its table, object layout or IK waypoints for grasp, stack and push. Those scenes follow its protocol (timings, gains, pads, masses, friction) on a layout defined here, so every engine is compared on identical inputs, but absolute positions are not the article's.

Option and determinism sensitivity

Each variant changes one setting relative to its baseline run on the same route. The variants cover cone type, native CCD, multi-contact CCD, impratio, the new 4.0 speculative contacts, the new 4.0 discrete integrator and IPC, a forced dense or sparse Jacobian (the mujoco#3767 check), the GPU determinism switches, and Genesis's own default options.

Runtime

Native batched stepping with no trace recording. Each case gets one warm-up trial, then the median of three timed trials from the same reset state. MuJoCo-Warp and Newton replay one CUDA graph per step, and the push controller runs on the device. Genesis batches through n_envs. The machine is an RTX 5090 with a Ryzen 9 9950X (32 threads).

Import audit

Every route reads back the masses, centres of mass, inertias, joint properties and forward kinematics it simulates. These are checked against MuJoCo 4.0 using the article's tolerances.
